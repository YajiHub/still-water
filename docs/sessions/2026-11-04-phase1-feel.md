## Mistakes & Gotchas
- **Stale scene link:** re-running *Build Level* deleted the Water object, leaving `PlayerMotor.water` = `{fileID: 0}`, so you fell to the pool floor. Fix: find `PoolWater` at runtime when the link is empty; `LookSwitch` finds its lights the same way.
- **"Ceiling bump":** `lowJumpMultiplier` 2.5 + quick phone taps = the jump died at once. Tuned to 1.5 (asset + code default).
- **The 3rd-person "nose" cube** sat in front of the first-person camera (visible in the Look A screenshot). First person now renders the body as shadows only.
- **Climbing backwards/sideways:** climb only checked distance. Now the edge must be within `climbMaxAngle` (60°) of facing.
- **Look C too dark**, and the edge glow too bright (it would drown out the Phase 2 reveal) → brighter C, glow emission 2× → 0.7× (below the bloom threshold).
- Laptop look didn't work at first: mouse-as-touch needed a left-drag on the right half. Added right-mouse and arrow-key look.
- Android caps at 30 fps unless `Application.targetFrameRate` is set.
- Fog must be saved **on** in the scene, or the build strips the fog shaders.
- Builder menus reuse existing assets (`MovementConfig`, looks, materials). New code defaults need the asset changed in the Inspector, or the asset deleted and rebuilt.
- A stale `.git/index.lock` (from an interrupted background `git status`) blocked `git add`. Checked that no git process was running, then removed it.
